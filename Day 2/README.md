# AI/ML Internship — Day 2 Project (Raritone)

## Overview

Day 2 of the AI/ML Internship focused on setting up the development environment and understanding the fundamentals of human pose detection using computer vision techniques. The primary goal was to explore how machines can detect and track human body movements in real time using AI-based models.

This task involved installing essential libraries, learning the concept of human pose landmarks, and implementing a basic pose detection system using MediaPipe and OpenCV.

---

## Objectives

The main objectives of this task were:

- To set up a proper AI/ML development environment  
- To install required libraries such as TensorFlow, OpenCV, and MediaPipe  
- To understand the concept of human pose detection  
- To learn about body landmarks and their importance  
- To implement a real-time pose detection system using webcam
