## Project Overview

This project focuses on researching and analyzing Artificial Intelligence and Computer Vision technologies used in modern Virtual Try-On systems. The internship involved studying body segmentation, pose estimation, garment mapping, 3D avatar generation, and human body reconstruction methods used in virtual fashion applications.

The objective was to understand how AI can improve online shopping experiences through realistic virtual clothing visualization and personalized user interactions.
