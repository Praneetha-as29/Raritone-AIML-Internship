# AI/ML Internship — Day 18

## Virtual Try-On Dataset Research & AI Workflow Documentation

### Objective

Research publicly available Virtual Try-On datasets and analyze the complete AI workflow used in modern fashion technology systems.

---

## Datasets Studied

### VITON
- 2D Virtual Try-On dataset
- Front-view clothing images
- Garment and pose annotations

### VITON-HD
- High-resolution Virtual Try-On dataset
- Improved image quality and garment details
- Suitable for advanced AI models

### Dress Code
- Multi-category clothing dataset
- Includes upper wear, lower wear, and dresses
- Supports modern Virtual Try-On research

### DeepFashion
- Large-scale fashion dataset
- Clothing attributes and landmark annotations
- Widely used for fashion AI applications

### MPV Dataset
- Multi-pose Virtual Try-On dataset
- Supports pose-aware garment fitting

### FashionGen
- Fashion recommendation dataset
- Includes product images and descriptions

---

## Recommended Datasets

- VITON-HD
- Dress Code
- DeepFashion

These datasets provide strong support for Virtual Try-On, garment fitting, and fashion recommendation systems.
